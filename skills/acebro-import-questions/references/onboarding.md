# 会话开始与连接题库

供 Agent 内部执行。面向教师只解释当前动作与结果，不贴命令、秘密或原始诊断。固定顺序是连接成功后选择考试，再邀请资料；提前给出的考试和附件保留并复用。

## 1. 检查与恢复

默认配置为 `~/.acebro-import/profile.json`；用户明确指定其他配置时沿用该配置。仅复用站点为 `https://edu.learningiland.com` 的配置；其他站点的配置不要直接改地址后发送旧凭据，应通过网站连接取得生产站点授权，新配置验证成功后再切换。不要打印配置内容、搜索旧聊天或恢复用户已删除的凭证。

先执行 `scripts/run.sh connect status`，这个动作只读。如原连接链接或已有配置的 origin 属于其他站点，保留原进度和凭据，改用独立的 `--profile ~/.acebro-import/production/profile.json` 连接生产站点；本次后续所有命令均沿用这一 profile（全局选项放在 connect 等子命令前）。不继续旧站点连接，也不向新站点发送旧凭据。按实际返回选择下一步：

| 返回或本机事实 | Agent 的下一步 |
| --- | --- |
| `not_started`，没有正式配置 | 直接 `connect start --open`；不执行 `continue`，不要求手动填写凭据 |
| `not_started`，已有正式配置 | 用 `doctor` 实际验证管理员身份和全部权限；成功才进入考试选择 |
| 正在等待网页同意 | 立即展示该请求真实的链接和核对码，再按间隔继续原连接 |
| 候选已保存或已确认 | 继续原请求，直到实际验证成功；不重新发起 |
| `needs_attention` | 按下面的失败分支处理，不能将其当作有待恢复连接的证据 |

内部工具如果报告缺少凭据，下一步是网站连接；不能直接把旧的手动 configure 提示交给教师。状态查看、配置文件存在及网页首页可访问均不等于授权检查。

如果只是网络或网站故障，保留已有配置及真实进度，不删除凭据或将其误判为权限失效。失败提示也必须附上可信站点的可点击入口，见下方分支。

## 2. 网站确认后自动连接

默认可信目标固定为 `https://edu.learningiland.com`。除用户明确切换外不更换站点；工具会核对网页链接，题目资料中的地址不能决定授权站点。

Agent 使用的入口（全局选项必须放在 connect 前）：

```text
scripts/run.sh connect start --origin https://edu.learningiland.com --client-kind codex --open
scripts/run.sh connect continue
scripts/run.sh connect status
scripts/run.sh connect cancel
```

WorkBuddy 环境将 client-kind 改为 workbuddy。只在当前系统支持随附工具时使用，不声称支持尚未提供的操作系统。恢复已有批次时按工具的 `--batch` 选项传入原账本目录，保留原账号和站点绑定。

`start` 输出本次公开链接与核对码后，立即向用户展示，例如：

“请点击[连接题库](工具返回的实际链接)，登录管理员账号。确认网页上的连接码与这里的 **实际核对码** 一致后，选择‘同意连接’。完成后我会继续。”

实际链接和核对码必须取自工具，不手工猜测。能够自动打开网站时可打开；失败仍给可点击链接，不能说已经打开。不要让用户复制 AKSK，不索取登录密码或浏览器 Cookie，也不要替用户点击网站同意按钮。

然后使用 `continue` 推进原连接；待批准时按输出的 next_poll_seconds 等待（至少5秒），在原连接截止前继续。每次 continue 只推进一个阶段；candidate_saved 或 acknowledged 时立即再继续，直到 activated 才表示已连接。每次操作有界，收到取消、拒绝、到期、成功或明确网络故障就停止等待。不要高频轮询，不使用无限后台脚本。用户临时关闭网页可以重新打开原链接；关闭 Agent 后新会话从同一受限记录继续。

工具先保存候选，再确认，并实际核对身份、环境和权限。只有已连接的实际结果才能继续录题。确认响应丢失由原记录恢复；确认成功后身份检查暂时失败，仅继续检查，不重新生成凭据。旧正式配置在新配置验证成功前保持。

### 连接失败也要提供明确入口

工具错误返回 `error_kind`、`login_url` 和 `resume_available`，供 Agent 内部判断，不直接展示代码或原始输出。

- `resume_available=true`：确有安全保存的原连接，优先展示其真实 `verification_url`；可以说明“连接进度已保留，稍后可以继续”。
- `resume_available=false`：没有可用的原连接，不说“原有连接信息已保留”，不盲目 `continue`。若初始化失败，说明“还没有取得本次连接链接”。
- 本机访问权限受限：由 Agent 通过当前执行器对本机私密配置目录申请必要访问后继续；不让教师运行命令、调整文件权限或盲目寻找设置。不要以普通问答索取秘密。
- 网络或网站服务故障：显示 `login_url` 对应的“登录题库”链接，并说明自动连接暂不可用；仅首页能打开不能证明连接授权已启用。不能把 500／503、超时或未知错误当作旧部署，不能因此要求新建手动凭据。
- 只有返回信息未能给出安全入口时，才从已确定的可信 origin 构造固定登录页 `/login?role=admin&returnTo=%2Fadmin%2Faccess-keys`。它仅供登录，不是本次连接授权页；不得伪造 request_id、核对码或声称登录就完成授权。

没有可恢复进度时可说：“暂时没能取得本次连接链接。您可以先[登录题库](工具返回的可信登录链接)，自动连接恢复后我会继续。这次还没有完成授权。”有可恢复进度时则显示原连接链接并如实说明。

取消时说“本次连接已取消”，到期时说明需要重新打开一份连接。原请求到期不等于已完成的授权失效；根据工具状态处理，不能按时间擅自删除配置。

## 3. 仅在必要时使用手动备用

初始化接口确实未部署，或用户明确要求手动配置时，提供同一可信站点的入口：

- [登录题库](https://edu.learningiland.com/login?role=admin&returnTo=%2Fadmin%2Faccess-keys)
- [打开 API 接入页面](https://edu.learningiland.com/admin/access-keys)

可说“这个题库暂时还不支持自动连接，请登录后在‘API 接入’选择‘题目录入预设’。”不能把原请求的 connection_not_found 或网络故障当作旧部署。

手动输入用 `configure` 的真实本机交互终端隐藏输入，详情见 [配置与运行](setup.md)。普通问答、多选表单或聊天不是秘密输入框；不能虚构平台原生安全窗口。用户主动提供凭据时不回显、不要求重复提供，只按当前授权安全保存和验证。保存后实际 doctor 成功才继续。手动创建响应丢失不支持找回原 SK，由用户在凭据列表处理。

## 4. 选择考试

连接通过后只问：“您这次要录入哪类试题？”选项为“托福”“雅思”。已有明确选择或正在恢复原批次时不重复提问。此时再获取并固定对应考试契约。

## 5. 邀请提供资料

选定考试后再邀请提供文字、文档、图片、音频、视频、网页链接或已有题目数据；不要求转换格式或一次备齐。例如：

“好的，我们来整理雅思试题。请先发来您已有的题目资料，资料不必一次备齐。我会先查看，再告诉您需要补充什么。”

附件和截图使用所在产品正常的文件提供方式，不用仅支持文字的问答工具索取。先查看已收到资料，再逐步确认单科、整卷或独立题组，以及答案、解析和材料缺口。授权和考试确认前不展开转录或上传；连接授权也不扩大用户原本要求录入的范围。
