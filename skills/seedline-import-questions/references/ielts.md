# 雅思转换

仅供 Agent 内部执行；对教师的回复遵循 [教师用语](communication.md)，不复制命令、字段或原始报错。

在本批固定 IELTS 契约加载成功后读取。首期支持 IELTS Academic 四科；具体字段、枚举和约束以下载并通过兼容检查的契约为准。

## 对象边界

- `ielts_question` 一行保存一个完整题包：一篇阅读、一段听力、一道写作任务或一个口语话题及所有依赖材料、小题、答案和解析。
- `ielts_paper` 是单科试卷，通过真实稳定题包 ID 引用内容。同批可先预分配 UUIDv7，引用已发布旧题包时用读接口获取当前真实内容。
- 不使用题号、文件名或临时别名充当服务端 ID；如使用 本地工具 支持的本地引用格式，必须由 本地工具 在首个写请求前替换并写入账本。

## 转录核对点

1. 保留分部、题组边界、题号、例题标志、计分位和答案顺序，使用对应科目的受支持题型。
2. 按契约保存完整材料与稳定句子 ID；新增或排序不重编号已有引用。中文译文与原句对应，解析定位引用真实句子，不复制一份易漂移的原文。
3. 答案、解析、干扰项说明和同义替换按实际适用性填写。无适用项用契约允许的空值；未知答案不作为无适用项处理。
4. 听力使用实际音频转写及真实时间轴，核对开始／结束时间和真实时长；图片、材料音频和参考音频分别使用契约指定 purpose。
5. 按下载契约的标签用途填写。剑桥目录的 book/test 与用途一致；机经题包不能因被某份文件收录就改成剑桥来源。

## 单科卷

本地校验器负责完整分部、连续计分位、四科对应任务及当前依赖可用性。不要通过复制题包或增造空题凑齐完整卷。写作和口语按契约的任务结构组卷，不套用客观题编号。

普通素材自动上传后才回填实际媒体 ID。可选解析视频使用真实发布目标及小题引用，在主体发布成功后由 本地工具 自动上传和绑定；视频失败独立报告，不撤销已发布内容。

最终提交时不设置 `status`、`dry_run` 或本地校验通过标志。成功题包与试卷由系统直接写为 `published`。
